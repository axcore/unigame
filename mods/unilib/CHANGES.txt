MAJOR NEW FEATURES
- You can use the new in-game system to create and edit remixes. You can also create and edit
    biomes, decorations and ores. If the "unimobs" expansion pack is loaded, you can configure where
    the mobs appear, what they like to eat, and so on. To get started, use the /unilib,
    /create_remix and /edit_remix commands (or the new welcome window). Any changes you make are
    applied when the game restarts. See the README for more information
- A new awards system, original to unilib. Awards are enabled by default (just add the "awards"
    remix). There are over 700 individual achievements for everything from mining diamonds to
    harvesting crops and exploring the world. The more achievements you earn, the higher your level
    in one of the career paths ("vocations") such as Lumberjack, Mountaineer and Geologist. Reach
    the highest levels of a career path to obtain a small reward! Use the /awards command to see
    your progress so far (or click the new button in your inventory, if you have a compatible
    inventory mod)
- A new atmosphere system, including weather effects, ambient sounds and environmental sounds. The
    new features are enabled in settings by default - just add the "atmosphere" remix to your game
- The new weather effects are original to unilib. They include various types of rain, hail, snow,
    storms, sandstorms, overcast skies and fog. Weather occurs on a regional basis, taking into
    account heat, humidity and elevation (using several layers of fractal noise). Weather is also
    persistent over (real) time. Use a weather forecasting console to see what weather to expect for
    the next few in-game days. As in real life, the forecast is not completely accurate. Use a
    weather monitoring station to keep track of the weather over time. If you want to test all the
    available weather effects, use the weather-switching machine and the weather-calming machine.
    Punch the machines to use them, or right-click to configure them. Weather effects are not
    dangerous (not even lightning). Puddles will evaporate eventually, but impatient players can use
    a water brush
- Ambient sounds are those connected to a particular type of place (e.g. birdsong in a forest).
    Sound files are typically quite large, so unilib currently provides just a single package
    providing ambient sound, "ambient_forest_light". This package is commented out in the
    "atmosphere" remix. If you want to test it, edit the packages.csv file in the remix
- Environmental sounds are those produced by specific nodes (e.g. the low rumbling sound produced
    by lava). All version of unilib provide lava and water sounds, but in this version the code has
    been refactored
- unigame uses the "playme" and "gaia" remixes by default. This version adds several new features to
    make the game a little easier for new players. The types of stone found just below surface dirt
    has been modified, such that there are many more biomes in which a player can mine stone using
    basic tools, in order to obtain cobble. In unigame, the "Stones have real-life hardness" setting
    is now disabled, by default. New soil types have been added, and there are more biomes in which
    the dirt can be used for growing crops. Jungle grass (providing cotton) is more plentiful. Dyes
    can be obtained from fruit, crops and produce, as well as from flowers. Several aesthetic
    improvements have also been added
    
MINOR NEW FEATURES
- When advanced cuisine is enabled, the player cannot eat unlimited quantities of the same item, in
    order to avoid death by starvation. Added a new Minetest setting, "Player can eat almost
    anything, if starving" (enabled by default in unigame, otherwise disabled by default)
- Added a bunch of new flags, all available in the "offend_flags" remix. Flags now use the wind
    generated by unilib's new weather system, if enabled; otherwise the "shared_offend_flags"
    package generates its own wind, as before
- The chat command provided by the "chat_test" package now has an optional parameter, for any code
    that might need it
- The tree chisel now makes a scraping sound, when used on tree trunks. Stripped tree trunks can now
    be used to craft planks (but only half as many as usual)
    
NEW PACKAGES
- Added marmite ("food_marmite" package). Some players will love it, and others will hate it!
- Added a lava sponge ("misc_sponge_fiery" package)
- Added a filtration box ("misc_box_filtration" package). When the "override_unilib_salt_water"
    package is loaded, ordinary water becomes salt water, which is not drinkable; use the
    filtration box to convert it into river water, which can be drunk
- Added a poison antidote ("potion_antidote_poison" package), which can be used to cure any unilib
    poison effect

- In the "gaia" remix, ores beneath the surface now match their surrounding stones, rather than
